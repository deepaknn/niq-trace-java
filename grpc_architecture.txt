CLIENT SIDE:
============

  Application Code
       |
       | sendMessage(Request)
       v
  ┌─────────────────────────────────────────────────────┐
  │  ClientCallImpl (instrumented)                        │
  │  - Constructor: Create span in InstrumentationContext│
  │  - start():    Inject headers, activate span         │
  │  - sendMessage(): **PAYLOAD CAPTURE POINT #1**       │
  │    @Advice.OnMethodEnter can access Object message   │
  │  - cancel():   Finish span                           │
  └─────────────────────────────────────────────────────┘
       |
       | Transport Layer
       | (TCP/HTTP2)
       |
       v
  ┌─────────────────────────────────────────────────────┐
  │  Server receives bytes, deserializes to protobuf obj │
  └─────────────────────────────────────────────────────┘

PROTOBUF MESSAGE CAPABILITIES:
================================================================================

Since messages are GeneratedMessage objects, you can:

1. Serialize to bytes:
   byte[] bytes = message.toByteArray();

2. Get string representation:
   String text = message.toString();

3. Access individual fields via generated getters:
   String name = ((Request) message).getName();

4. Use reflection for generic access:
   for (Method m : message.getClass().getMethods()) {
     if (m.getName().startsWith("get") && m.getParameterCount() == 0) {
       Object fieldValue = m.invoke(message);
     }
   }

5. Check field presence:
   boolean hasField = message.hasField(descriptor);

6. Convert to JSON (with protobuf-json library):
   String json = JsonFormat.printer().print(message);

CONTEXT STORE PATTERN FOR CROSS-METHOD DATA:
================================================================================

Pattern for storing data across bytecode instrumented methods:

1. Define in instrumentation:
   @Override
   public Map<String, String> contextStore() {
     return Collections.singletonMap(
       "io.grpc.ClientCall", 
       "com.example.PayloadData");
   }

2. Store in one method:
   InstrumentationContext.get(ClientCall.class, PayloadData.class)
     .put(call, data);

3. Retrieve in another method:
   PayloadData data = InstrumentationContext.get(
     ClientCall.class, PayloadData.class).get(call);

This allows associating spans with payloads across method calls.
